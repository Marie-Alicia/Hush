Hush

A clickable prototype. Sam is the parent of Isla, who is seven weeks old. Hush listens through a NotePin S, the iPhone or their baby monitor. It spots each cry, gives a guess based on Isla's own history, and learns from what actually settled her. It also looks after Sam: calming down at 3am, sharing nights with Jordan, and support when things get heavy.

    Sample data. No audio is recorded or analysed here. Step 17 runs the stream-test logic on simulated audio; the real Swift code is below the phone.

    NotePin S → YAMNet stream test

    This code runs inside Plaud's iOS template app. Each audio chunk from the pin goes into a sliding YAMNet window, and cries become episodes with a saved WAV clip. Every frame is logged to a CSV so you can check it against what really happened that night.

    1. NotePin SblePcmData(sessionId:millsec:pcmData:isMusic:)
    640 B · 16 kHz · mono · ~20 ms
    2. HushAudioTapingest(sessionId:millsec:pcm:)
    one line added to DeviceManager
    3. CryDetector15,600-sample window, hop 0.48 s
    YAMNet · 3-frame smoothing · 0.35 / 0.20
    4. Evidencecries/*.wav · frames.csv
    cry clips only; other audio isn't stored
